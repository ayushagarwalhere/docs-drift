How it works

Scan

Find every statement your code no longer supports.

01

Reads your Markdown, indexes argparse, Click, Typer, FastAPI, Flask, Commander and Express, and matches each claim to a real declaration. Rule-based. Your code is never run.

Try one stale claim {{ arrow() }}
$ docs-drift scan

README.md:4
  renamed  --port
  → --listen
  450a93d

README.md:6
  default  4 → 8

5 findings · 10 claims

Gate

(and fail only on drift a pull request introduces)

02

Add the GitHub Action to CI. Reports come out as SARIF, JUnit, JSON, HTML and Markdown, and a baseline keeps old drift from blocking new work.

GitHub Action guide {{ arrow() }}
docs.yml

on: [pull_request]
jobs:
  docs:
    steps:
      - uses: actions/checkout
      - uses: docs-drift
        with:
          fail-on-drift: true

Fix

Review a patch, not a guess.

03

docs-drift fix previews a documentation patch built from source evidence. Nothing is written without an explicit flag. VS Code shows the same findings with quick fixes.

VS Code extension {{ arrow() }}
$ docs-drift fix

--- README.md
+++ README.md
@@ -4 +4 @@
-`serve` accepts --port
+`serve` accepts --listen

Works where you already work.

One engine, six ways in. Same findings, same evidence, everywhere.

01

Terminal

Scan any checkout. Explain one finding. Preview a patch.

$ pipx install docs-drift
$ docs-drift scan
$ docs-drift fix
For maintainers and contributors
02

Pull requests

A GitHub Action or App comments on the PR with a one-click suggested fix, and fails only on drift the PR introduces.

- uses: ayushagarwalhere/docs-drift@v0.1.1
  with:
    mode: pr-review
    comment: 'true'
For teams and OSS orgs
03

AI coding agents

An MCP server lets Claude Code, Cursor and Copilot check a paragraph before writing it, and after every rename.

$ claude mcp add docs-drift -- \
    uvx --from "docs-drift[mcp]" \
    docs-drift mcp
For anyone writing docs with an agent
04

Tests and hooks

A pytest plugin and a pre-commit hook make stale docs a failing test.

$ pytest --docs-drift

- repo: https://github.com/ayushagarwalhere/docs-drift
  hooks: [{id: docs-drift}]
For projects that treat docs as code
05

Dependencies

Catches "requires Python 3.8" when the package needs 3.9, unknown extras, and imports nobody declared.
