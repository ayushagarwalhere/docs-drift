Findings

Claims appear here as you speak.

    Mention a flag like --port, a command, an env var or a setting and it shows up here with the evidence from the code.

    Three steps, no keyboard required.

    1. 01

      Dictate

      Click into the draft and hold your dictation key. Wispr Flow types wherever the cursor is, so the text lands here as you speak.

    2. 02

      Pause

      About 0.6 s after a burst of words, every flag, command, endpoint, env var, setting and default is matched against the saved static index of the repository.

    3. 03

      Apply

      Accept a suggestion to rewrite just that span, then copy the Markdown into your README. Nothing is executed; nothing leaves the page but your text.

    Static index only: Git history is not re-run for text you write here, so renames come from index near-misses or from the saved scan of the same claim. The same check runs in VS Code as you dictate and in AI agents through MCP — see the guide and how this was built with voice.
