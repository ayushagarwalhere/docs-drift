# Initial local portfolio trial — 22 October 2026

This is an agent-run functional trial on existing local public-repository
checkouts, not an independent human evaluation, deployment test, maintainer
endorsement or organization-scale capacity benchmark. No source code was
executed and no model API key was used.

## Input and results

The initial manifest mistakenly pointed to wrapper directories containing the
checkouts. Those runs had zero Git SHAs and must not be used as repository
evaluation results. That mistake prompted a safeguard: portfolio entries now
require a checkout-root `.git` marker unless an unversioned snapshot is explicitly
selected. Empty extraction and missing Git revisions are visible in gate warnings.

## Product implication

The organization dashboard and CI adoption controls function, but this sample
blocks any claim that default enforcement is ready for these organizations.
Keep framework/tutorial repositories in report-only mode while extraction and
project-owned-command scope are improved and independently evaluated. A baseline
must not be presented as a fix for detector errors. These cases remain visible;
no answer key, benchmark label or threshold was adjusted to improve reported
accuracy.
