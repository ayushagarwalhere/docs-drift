# Reporting a vulnerability

Please use **Security → Advisories → Report a vulnerability** in the GitHub
repository hosting this project. Include the affected version/commit, a minimal
reproducer and impact. Avoid posting secrets, sensitive repository content or
live exploit details in public issues. If private reporting is not enabled,
open a public issue asking the maintainer for a private contact without including
the exploit. A dedicated security contact has not yet been supplied.

The threat model, mitigations and remaining limits are in [SECURITY.md](SECURITY.md).
